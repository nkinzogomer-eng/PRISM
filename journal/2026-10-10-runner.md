# PRISM Runner Step: 2026-10-10

## Built

- `prism/oracle.py`: the hidden world lives only here. The solver receives answers to requested observations.
- `prism/runner.py`: executes a policy's observation order against the oracle, certifies only through the verifier, and abstains with `declared_class_contradicted` when an answer kills every declared hypothesis.
- `prism/generators.py`: now keeps the full world table for the oracle and removes the hidden world from the declared problem.
- `prism/policies.py`: policies return observation orders only and cannot read answers.
- Test suite rewritten to run with the standard library (no pytest dependency).

## Local result

20 tests run: 19 pass, 1 expected failure. The expected failure is the misspecification gate below.

## Important negative result (not hidden)

On 200 misspecified seeds, both fixed-cost and greedy policies reached a certified decision in every run, and a large share of those certificates gave the wrong decision for the true world (301 of 400 certifications were wrong in the first probe).

Cause: a certificate is sound relative to the declared hypothesis class. When the true world is outside that class, the observed answers can still match some declared hypotheses that agree with each other, so PRISM certifies within the class. The runner only detects contradiction when every declared hypothesis is eliminated, which is rare before the end.

The benchmark gate "correct abstention on omitted-world instances" is therefore NOT met. It is recorded as `test_KNOWN_FAILURE_...`.

## Options for a human decision

1. Keep certificates scoped to the declared class and label every output accordingly (already the contract). Misspecification then remains outside the guarantee.
2. Add an independent consistency test: predict held-out observations from the surviving class and abstain on any mismatch. This costs extra observations and must be counted.
3. Require full observation before certifying under declared misspecification risk. This is correct but usually too expensive, which defeats the purpose.

No option is chosen yet. Option 2 is the most promising to test first, since it is a measurable mechanism, not a relabelling.

## Next step
